# Araucaria VPS Manager v1.0.0

Первый стабильный выпуск моей утилиты для установки и управления Xray-core на собственном VPS без Docker и веб-панелей.

## Возможности

- Чистая установка на Ubuntu 22.04 LTS или 24.04 LTS.
- VLESS + REALITY + Vision и готовая ссылка для ВПН-клиента.
- Настройка UFW, Fail2ban, автоматических обновлений безопасности Ubuntu и отдельного непривилегированного пользователя Xray.
- Команды для смены порта, имени профиля, UUID и REALITY-ключей.
- Ручная проверка новой стабильной версии Xray, обновление с подтверждением работоспособности VPN и возможность отката.
- Официальный стабильный Xray-core при установке; проверка SHA-256 закреплённого установщика XTLS.

## Установка

Выполните под `root` на **чистом VPS**:

```bash
apt-get update && apt-get install -y git
git clone --depth 1 --branch v1.0.0 https://github.com/Dindinlinius/araucaria-vps-manager.git
cd araucaria-vps-manager
bash install.sh
```

Установщик покажет план изменений перед подтверждением. Держите первую SSH-сессию открытой до проверки повторного входа. Полная инструкция — в [README](README.md).

## Проверки

- Реальная чистая установка и работа VPN на Ubuntu 22.04 и 24.04.
- Смена VLESS-порта, переименование, ротация параметров доступа, повторное SSH-подключение, UFW/Fail2ban и работа после перезагрузки.
- Автоматические проверки на Ubuntu 22.04/24.04, включая негативные сценарии ввода, отказ от опасных действий, целостность скачивания, сохранение конфигурации и откат после сбоев.

**Ограничение:** реальное обновление Xray между двумя разными версиями пока не проверялось на VPS. Соответствующие сценарии покрыты автоматическими тестами; при выходе новой версии обязательно проверьте VPN перед подтверждением `yes`.

Установка на VPS с уже работающим Xray, веб-панель, Trojan и несколько VLESS-клиентов не поддерживаются.

# Araucaria v1.0.0-rc1 — предварительный релиз

Первая публичная тестовая версия Araucaria VPS Manager. Предназначена для **чистого VPS**, а не обновления поверх существующего Xray.

## Что входит

- Автоматическая настройка VLESS + REALITY + Vision на Ubuntu 22.04/24.04.
- UFW с сохранением SSH-портов, Fail2ban и автоматические обновления безопасности Ubuntu.
- Отдельный непривилегированный пользователь службы Xray.
- Готовая VLESS-ссылка и команды управления: `vless-link`, `vless-port`, `vless-name`, `vless-rotate`, `araucaria status`.
- Ручное обновление Xray: `araucaria xray check`, `araucaria xray update`, `araucaria xray rollback`.
- Проверка нового Xray перед заменой; подтверждение работы ВПН-клиента (`yes`) либо откат (`no`).
- При новой установке выбирается последний официальный **стабильный** Xray-core. Код `XTLS/Xray-install` скачивается из конкретного коммита и сверяется с закреплённым SHA-256.
- Управляемые повторы исправимых шагов установки с понятной диагностикой; опасные ошибки не пропускаются.

## Что важно перед установкой

1. Используйте только новый VPS и сохраните SSH-сессию до повторной проверки входа.
2. У провайдера может быть отдельный внешний файрвол; TCP-порт VLESS нужно разрешить и там.
3. Готовую VLESS-ссылку не публикуйте. Она содержит данные доступа.
4. Обновление Xray перезапускает службу. Возможен кратковременный разрыв соединения. Если откат не удался, используйте аварийную консоль VPS и резервные копии.
5. Тестовая команда `--test-reinstall` **не входит** в публичный релиз.

## Известные ограничения

Поддерживаются Ubuntu 22.04/24.04, одна конфигурация VLESS + REALITY и один клиент. Автообновление самого Xray выключено; нет веб-панели, Trojan и автоматической настройки внешнего файрвола провайдера.

## Проверки

Автоматические тесты, синтаксис Bash/Python и контрольная сумма официального XTLS-установщика проверяются в GitHub Actions на Ubuntu 22.04 и 24.04. Перед пометкой `v1.0.0` как стабильной версии требуется обратная связь от пользователей публичного предварительного релиза.

Полная инструкция, установка и диагностика — в [README](README.md).

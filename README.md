# Araucaria VPS Manager

### Установка на чистый VPS

```bash
apt-get update && apt-get install -y git
git clone --depth 1 --branch v1.0.0 https://github.com/Dindinlinius/araucaria-vps-manager.git
cd araucaria-vps-manager
bash install.sh
```

**Что произойдёт при запуске:** установщик проверит Ubuntu и SSH-порт, предложит имя VPN-профиля и покажет план изменений. После подтверждения `yes` он установит стабильный Xray-core, настроит VLESS + REALITY + Vision, UFW и Fail2ban, запустит службу и выдаст готовую `vless://`-ссылку. Её останется импортировать в ВПН-клиент.

Я сделал Araucaria для простой настройки **собственного VPS без Docker и веб-панелей**. Всё управление из SSH-терминала. Программа рассчитана на один сервер с одним VPN-подключением.

## Перед установкой

- Нужна **чистая Ubuntu 22.04 LTS или 24.04 LTS**, systemd и доступ к серверу под `root`. Не запускайте установщик поверх существующего Xray.
- Желательно иметь аварийную консоль в панели хостинга. **Не закрывайте текущий SSH-сеанс**, пока не проверите вход во втором окне.
- Сервер должен иметь доступ к интернету и публичный IPv4. Если у провайдера есть отдельный файрвол, откройте в нём выбранный TCP-порт VLESS.
- Установщик использует права `root`. Перед запуском можно самостоятельно изучить `install.sh`.

По умолчанию REALITY использует `www.google.com:443` как TLS-цель, а порт подключения выбирается случайно из диапазона 1024–65535 с исключением занятых и зарезервированных портов.

### Параметры запуска

```bash
bash install.sh --name "Мой VPN" --port 56399
```

Необязательные параметры: `--name` (имя профиля), `--port` (порт VLESS), `--target` (REALITY-сайт), `--ssh-port` (дополнительный SSH-порт), `--strict-fail2ban`, `--no-upgrade`, `--yes` и `--help`.

Без параметров установщик задаст необходимые вопросы сам. Имя профиля поддерживает кириллицу и пробелы. Строгий режим Fail2ban (`--strict-fail2ban`: две ошибки за три минуты — бан на 72 часа) не рекомендуется без аварийного доступа к VPS.

## Управление

Команды выполняются под `root` после установки.

| Команда | Действие |
| --- | --- |
| `vless-link` | Показать текущую VLESS-ссылку |
| `vless-name` | Переименовать профиль через ввод |
| `vless-name "Мой VPN"` | Переименовать сразу |
| `vless-port` | Выбрать новый порт вручную или случайно |
| `vless-port --random` | Установить случайный доступный порт |
| `vless-port 38421` | Установить конкретный порт |
| `vless-rotate` | Сменить UUID, REALITY-ключи и Short ID |
| `araucaria status` | Проверить Xray, UFW и Fail2ban |
| `araucaria xray check` | Проверить доступность новой стабильной версии Xray |
| `araucaria xray update` | Обновить Xray с ручной проверкой VPN |
| `araucaria xray rollback` | Восстановить Xray после незавершённого обновления |
| `araucaria commands` | Показать подсказку по командам |

После **смены порта** нужно импортировать обновлённую ссылку в клиент. После **ротации ключей** старые ссылки перестанут работать — импортируйте новую. **Переименование** меняет только отображаемое имя и не перезапускает Xray.

Если внешний IP не удалось определить автоматически, используйте `vless-link --ip ВНЕШНИЙ_IP_VPS`. Параметр `--ip` также поддерживается командами смены имени, порта и ключей.

## Обновление Xray

Araucaria при первичной установке загружает **последний официальный стабильный выпуск Xray-core** (не beta/pre-release) через официальный установщик [XTLS/Xray-install](https://github.com/XTLS/Xray-install). Код внешнего установщика закреплён за проверенным коммитом и сверяется по SHA-256.

**Xray автоматически не обновляется.** Для обновления запустите:

```bash
araucaria xray check
araucaria xray update
```

Если появилась новая стабильная версия, программа попросит разрешение, скачает и проверит Xray, сохранит прежний исполняемый файл, перезапустит службу и попросит проверить VPN **до закрытия SSH-сеанса**.

- Ответ `yes` — сохранить новую версию.
- Ответ `no` — попытаться вернуть предыдущую версию.

При неудачном перезапуске также предусмотрена попытка отката. Если процесс оборвался из-за отключения питания или принудительного завершения, автоматический откат не гарантирован: после восстановления доступа может понадобиться `araucaria xray rollback`.

## Безопасность

Я оставил SSH-доступ под контролем владельца сервера: Araucaria **не меняет пароль SSH, не отключает вход под root и не запрещает вход по паролю**.

При установке программа настраивает UFW (разрешает SSH и VPN-порт), Fail2ban для SSH (обычно 5 ошибок за 10 минут — блокировка на 12 часов), автоматические обновления безопасности Ubuntu и отдельного непривилегированного пользователя `araucaria-xray` для службы.

**Не публикуйте VLESS-ссылку, UUID, приватный REALITY-ключ или файл `/usr/local/etc/xray/config.json`.** Ссылка содержит данные доступа к VPN.

## Если что-то не работает

```bash
araucaria status
systemctl status xray --no-pager -l
journalctl -u xray -n 50 --no-pager
ufw status verbose
fail2ban-client status sshd
```

Проверьте TCP-доступность порта с клиентского устройства и правила внешнего файрвола провайдера. При сбое установки сначала прочитайте подсказку на экране: некоторые шаги можно повторить в том же процессе. **Не запускайте установщик повторно поверх частично установленной системы** без диагностики.

После установки обновить цвет приглашения уже открытого Bash можно командой `source /root/.bashrc`.

О найденных ошибках можно сообщить в [Issues](https://github.com/Dindinlinius/araucaria-vps-manager/issues). Перед отправкой логов уберите секреты и личные данные.

## Проверки и ограничения

Я проверил чистую установку и работу VPN на **Ubuntu 22.04 и 24.04**, а также смену порта, переименование, ротацию ключей, SSH, файрвол и работу после перезагрузки. Автоматические тесты дополнительно проверяют ошибки ввода, сохранность конфигурации, UFW и сценарии отката Xray. **Реальное обновление Xray между двумя разными версиями пока отдельно не подтверждено**; при его выполнении обязательно проверяйте подключение.

Проект предназначен для **одного VLESS + REALITY-подключения**. Я не добавлял веб-панель, Trojan, управление несколькими пользователями или автоматическую настройку файрвола провайдера.

# 🌲 Araucaria VPS Manager — v0.1.0

**Установка Xray (VLESS + REALITY), UFW и Fail2ban на новом VPS без 3x-ui и Docker.**

Сделано для новичка: запускаешь установщик один раз, затем получаешь готовую VLESS-ссылку с именем `USAraucaria`.

> **Важно.** Это первая версия. Скрипты прошли локальные проверки, но ещё **не испытаны на реальном чистом VPS от начала до конца**. Первый запуск делай только на новом тестовом VPS с доступной аварийной консолью хостинга. Не запускай на уже настроенном сервере. Установщик специально останавливается при обнаружении существующего Xray.

## Что устанавливается

- Обновления Ubuntu и ежедневные автоматические обновления безопасности Ubuntu (автоматические перезагрузки не включаются).
- **UFW**: запрет входящих соединений по умолчанию на новом сервере; открыты обнаруженные SSH-порты и один TCP-порт Xray.
- **Fail2ban**: защита SSH. По умолчанию 5 неудачных попыток за 10 минут → блокировка на 12 часов.
- Официальный **Xray-core** с VLESS + REALITY + Vision, маскировка под `www.google.com:443`.
- Отдельный непривилегированный пользователь **для службы Xray** `araucaria-xray` (это НЕ новая SSH-учётная запись).
- Команды `vless-link`, `vless-rotate`, `araucaria status`.
- Резервные копии конфигурации при первичной настройке и при ротации ключей.

**Не меняются:** твой SSH-пароль, разрешение входа под `root`, SSH-ключи. Их укрепление рекомендуется отдельно.

**В этой версии ещё нет Trojan.** Он запланирован как отдельное расширение. Для стандартного Trojan+TLS нужен домен и сертификат.

## Требования

- **Новый, чистый VPS** с Ubuntu **22.04 LTS или 24.04 LTS**, systemd, root-доступом.
- Рабочий интернет на VPS; доступность официального GitHub/Xray release.
- Открытый SSH у провайдера. У некоторых провайдеров есть дополнительный **внешний файрвол/панель Security Group** — входящий TCP-порт Xray надо открыть там вручную.
- Аварийная консоль VPS у провайдера настоятельно рекомендуется.
- Собственный домен для REALITY **не нужен**.

## Быстрый старт (сейчас, через ZIP)

1. Скачай архив `araucaria-vps-manager-v0.1.0.zip` из чата на свой компьютер.
2. Отправь архив на **НОВЫЙ** VPS. В PowerShell (в папке с архивом):

   ```powershell
   scp .\araucaria-vps-manager-v0.1.0.zip root@IP_НОВОГО_VPS:/root/
   ```

3. Подключись по SSH к новому VPS и введи:

   ```bash
   apt-get update && apt-get install -y unzip
   cd /root
   unzip araucaria-vps-manager-v0.1.0.zip
   cd araucaria-vps-manager
   bash install.sh
   ```

4. Подтверди установку, напечатав **`yes`**. Установщик покажет обнаруженные SSH-порты, случайный порт VLESS и целевой сайт REALITY **до внесения изменений**.
5. После установки скрипт выведет готовую `vless://...` ссылку. Импортируй её в Hiddify.
6. **Не закрывай первое SSH-подключение**, пока не откроешь второе и не проверишь, что вход доступен. Убедись, что подключение Hiddify работает.

> Если ты подключён к VPS через нестандартный SSH-порт, который установщик не определил, остановись и используй `bash install.sh --ssh-port НОМЕР_ПОРТА`.

## Команды после установки

```bash
vless-link             # Показать ссылку, ничего не меняя
vless-rotate           # Создать новые UUID/REALITY-ключ/Short ID и выдать новую ссылку
araucaria status       # Xray + UFW + Fail2ban
```

Если публичный IP не определяется автоматически:

```bash
vless-link --ip ПУБЛИЧНЫЙ_IP
vless-rotate --ip ПУБЛИЧНЫЙ_IP
```

`vless-rotate` **отключит старые ссылки**. Если сервер не примет новую конфигурацию, программа попытается восстановить предыдущую из резервной копии. По умолчанию Google и TCP-порт **не меняются**.

**Не отправляй кому-либо полученную VLESS-ссылку или `config.json`** — ссылка позволяет подключаться к твоему серверу. API определения IP получает только IP самого сервера; ключи и UUID никуда не отправляются.

## Дополнительные параметры

```bash
bash install.sh --help
bash install.sh --port 56399                      # фиксированный порт
bash install.sh --target www.google.com           # вручную указать REALITY-домен
bash install.sh --name USAraucaria                # имя в ссылке
bash install.sh --strict-fail2ban                 # 2 ошибки/3 мин -> бан на 72 ч!
bash install.sh --ssh-port 2222                   # дополнительно открыть SSH-порт 2222
bash install.sh --yes                             # без подтверждающего вопроса
bash install.sh --no-upgrade                      # пропустить полное обновление пакетов
```

Не применяй `--strict-fail2ban`, пока не убедишься, что у тебя есть аварийная веб-консоль: две ошибки в пароле могут заблокировать твой IP на трое суток.

## Где лежат файлы

| Файл | Назначение |
|---|---|
| `/usr/local/etc/xray/config.json` | Рабочие настройки Xray (секреты; root + группа службы) |
| `/etc/araucaria/settings.json` | Имя профиля |
| `/usr/local/bin/araucaria` | Управление Xray |
| `/usr/local/bin/vless-link` | Показ ссылки |
| `/usr/local/bin/vless-rotate` | Смена ключей |
| `/etc/fail2ban/jail.d/araucaria-sshd.local` | Защита SSH |
| `/etc/systemd/system/xray.service.d/20-araucaria-hardening.conf` | Ограниченные права службы |
| `/var/backups/araucaria/` | Резервные копии (доступны root) |

## Если что-то пошло не так

**Xray не запускается:**

```bash
systemctl status xray --no-pager -l
journalctl -u xray -n 40 --no-pager
xray run -test -config /usr/local/etc/xray/config.json
```

**UFW:**

```bash
ufw status verbose
ss -ltnp | grep xray
```

**Fail2ban:**

```bash
fail2ban-client status sshd
```

Если случайно заблокировал свой IP, войди через аварийную консоль провайдера:

```bash
fail2ban-client set sshd unbanip ТВОЙ_ВНЕШНИЙ_IP
```

**После ошибки установки** не запускай её повторно вслепую. Установка нескольких компонентов может быть частичной. Сохрани текущую SSH-сессию и посмотри, на каком шаге остановилась программа. Самый простой путь для тестового VPS — переустановить чистую Ubuntu и повторить запуск после разбора причины.

## Технические заметки

- Используется [официальный Xray-install](https://github.com/XTLS/Xray-install) и [спецификация REALITY](https://github.com/XTLS/Xray-docs-next/blob/main/docs/en/config/transports/reality.md). Xray скачивается на время установки из официального источника (скрипт не привязан к фиксированной версии); перед будущей публикацией рекомендуются фиксация версии и проверка источника.
- UFW открывает IPv4/IPv6 в соответствии с настройками системы. Если UFW **уже активен**, установщик сохраняет существующие политики, не удаляет чужие правила.
- Пользователь Xray запускает службу без привилегий; конфигурация имеет права `0640`, резервные копии — `0600`.
- Проверка Xray включает валидацию JSON его собственной командой, перезапуск службы и TCP-соединение с локальным портом.
- Ротация блокируется файловой блокировкой, проверяет новый конфиг и делает резервную копию перед применением.
- Автоматическое обновление **самого Xray** в этой версии не включено: обновлять вручную, предварительно сохранив конфигурацию. Автообновления касаются системных пакетов Ubuntu.
- Тесты без установки на VPS: `python3 -m unittest discover -s tests -v`.

**Статус версии:** v0.1.0 (MVP, требуется полевой тест на чистом VPS).

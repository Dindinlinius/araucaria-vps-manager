# 🌲 Araucaria VPS Manager — v0.2.0-rc2

**Установка Xray (VLESS + REALITY), UFW и Fail2ban на новом VPS без 3x-ui и Docker.**

Сделано для новичка: запускаешь установщик один раз, выбираешь название профиля и получаешь готовую VLESS-ссылку (по умолчанию `USAraucaria`).

> **Важно.** Первая установка v0.2.0-rc2 уже успешно завершилась на тестовом VPS, но проверка клиентского подключения и команд управления ещё продолжается. Для первой установки используйте только чистый тестовый VPS с аварийной консолью хостинга. `install.sh` никогда не запускайте на уже настроенном сервере — он специально останавливается при обнаружении существующего Xray.

## Что устанавливается

- Обновления Ubuntu и ежедневные автоматические обновления безопасности Ubuntu (автоматические перезагрузки не включаются).
- **UFW**: запрет входящих соединений по умолчанию на новом сервере; открыты обнаруженные SSH-порты и один TCP-порт Xray.
- **Fail2ban**: защита SSH. По умолчанию 5 неудачных попыток за 10 минут → блокировка на 12 часов.
- Официальный **Xray-core** с VLESS + REALITY + Vision, маскировка под `www.google.com:443`.
- Отдельный непривилегированный пользователь **для службы Xray** `araucaria-xray` (это НЕ новая SSH-учётная запись).
- Команды `vless-link`, `vless-rotate`, `vless-port`, `vless-name`, `araucaria status` и `araucaria commands`.
- Резервные копии конфигурации при первичной настройке, ротации ключей и смене порта.
- Жёлтые имя пользователя и имя VPS в приглашении **Bash** (`/root/.bashrc`); это не настройка цвета в самом приложении Termius. Действует с нового SSH-сеанса.
- После установки — подробный отчёт и отдельный блок всех команд управления.

**Не меняются:** твой SSH-пароль, разрешение входа под `root`, SSH-ключи. Их укрепление рекомендуется отдельно.

**В этой версии ещё нет Trojan.** Он запланирован как отдельное расширение. Для стандартного Trojan+TLS нужен домен и сертификат.

## Требования

- **Новый, чистый VPS** с Ubuntu **22.04 LTS или 24.04 LTS**, systemd, root-доступом.
- Рабочий интернет на VPS; доступность официального GitHub/Xray release.
- Открытый SSH у провайдера. У некоторых провайдеров есть дополнительный **внешний файрвол/панель Security Group** — входящий TCP-порт Xray надо открыть там вручную.
- Аварийная консоль VPS у провайдера настоятельно рекомендуется.
- Собственный домен для REALITY **не нужен**.

## Быстрый старт (сейчас, через ZIP)

1. Скачай архив `araucaria-vps-manager-v0.2.0-rc2.zip` из чата на свой компьютер.
2. Отправь архив на **НОВЫЙ** VPS. В PowerShell (в папке с архивом):

   ```powershell
   scp .\araucaria-vps-manager-v0.2.0-rc2.zip root@IP_НОВОГО_VPS:/root/
   ```

3. Подключись по SSH к новому VPS и введи:

   ```bash
   apt-get update && apt-get install -y unzip
   cd /root
   unzip araucaria-vps-manager-v0.2.0-rc2.zip
   cd araucaria-vps-manager
   bash install.sh
   ```

4. Сначала введи желаемое имя VLESS-ссылки или нажми Enter для имени `USAraucaria`. Затем подтверди установку, напечатав **`yes`**. Установщик покажет обнаруженные SSH-порты, случайный порт VLESS и целевой сайт REALITY **до внесения изменений**.
5. После установки скрипт выведет готовую `vless://...` ссылку. Импортируй её в Hiddify.
6. **Не закрывай первое SSH-подключение**, пока не откроешь второе и не проверишь, что вход доступен. Убедись, что подключение Hiddify работает.

> Если ты подключён к VPS через нестандартный SSH-порт, который установщик не определил, остановись и используй `bash install.sh --ssh-port НОМЕР_ПОРТА`.

### Новое в версии v0.2.0-rc2

**Случайный порт:** выбирается из всего диапазона `1024–65535` как при первой установке, так и в `vless-port`. Программа пропускает занятые TCP-порты, SSH-порты, существующие правила UFW и проверяет возможность привязки сокета.

**Название VLESS-ссылки:** установщик спрашивает имя перед подтверждением; Enter оставляет `USAraucaria`. Если ввести некорректное название, установщик объяснит ошибку и предложит повторить ввод, не прерывая установку. Завершающие `\r`, случайно добавленные SSH-клиентом, игнорируются. При автоматической установке можно указать `--name "Мой VPN"` (некорректное значение `--name` по-прежнему останавливает запуск до изменения сервера).

Для переименования на уже настроенном сервере:

```bash
vless-name                    # Спросить новое имя
vless-name "США — личный VPN"  # Переименовать сразу
araucaria name "Мой VPN"     # Эквивалентная команда
```

Допускаются русский язык, пробелы и эмодзи; ограничение 64 символа и 192 байта UTF-8. Символы имени безопасно кодируются в конце ссылки после `#`. Изменяется только это название: **UUID, ключи, SNI, порт, конфигурация и служба Xray не меняются**. Старые подключения продолжают работать, но имя в Hiddify обновится после повторного импорта ссылки или ручного переименования.

**Статус:** автоматические тесты пройдены; полевое испытание функций на тестовом VPS ещё требуется.
### Жёлтое приглашение в Bash / Termius

Установщик добавляет цветное приглашение `root@hostname` в `/root/.bashrc` и не меняет пароль или настройки SSH. Если установщик запущен как `bash install.sh`, он **не может изменить приглашение текущего родительского Bash-процесса**. Чтобы увидеть жёлтое имя немедленно после установки, выполни:

```bash
source /root/.bashrc
```

При следующем SSH-входе настройка применится автоматически. Установщик показывает эту инструкцию отдельным блоком в конце работы. Вопрос о подтверждении: «Продолжить установку? Напиши yes:».

## Команды после установки

```bash
vless-link              # Вывести действующую VLESS-ссылку; ничего не меняет
vless-rotate            # Заменить UUID + ключ REALITY + Short ID; старая ссылка отключится
vless-port              # Интерактивная смена TCP-порта: yes = случайный, число = свой порт
vless-port --random     # Случайный TCP-порт без вопроса
vless-port 38421        # Конкретный TCP-порт без вопроса
vless-name              # Переименовать VLESS-ссылку интерактивно
vless-name "Мой VPN"     # Задать название сразу
araucaria status        # Проверка Xray, UFW, Fail2ban
araucaria commands      # Показать все команды
araucaria --help        # Справка по параметрам
```

### Смена порта VLESS

Запусти `vless-port` под `root`. Программа покажет текущий порт, занятые TCP-порты (слушающие сокеты), допустимый диапазон **1024–65535** и диапазон случайного выбора **1024–65535**. Введи `yes`, чтобы получить случайный свободный порт, либо целое число из допустимого диапазона.

Аraucaria проверит доступность нового TCP-порта и существующие правила UFW. Затем она **сначала откроет новый порт в UFW**, проверит и применит конфигурацию Xray, и только после успешного запуска **закроет старый порт**. Программа выведет итоговый отчёт и новую ссылку. UUID, ключ REALITY, Short ID и SNI при смене порта **не меняются**. Сохранённый профиль Hiddify нужно обновить/импортировать снова.

Если при запуске Xray или изменении UFW возникнет ошибка, программа попытается восстановить прежнюю конфигурацию и правила. При невозможности полного отката выведет понятную ошибку и не станет скрывать проблему. **Если провайдер VPS использует собственный внешний файрвол**, новый порт нужно разрешить также в панели провайдера: локальный UFW не может изменить внешние правила.

`vless-rotate` **отключит старые ссылки** и не изменит Google или TCP-порт. При ошибке перезапуска Xray программа попытается восстановить конфигурацию из резервной копии. Не публикуй VLESS-ссылку или `config.json`: они дают доступ к VPN.

Если публичный IP не определяется автоматически:

```bash
vless-link --ip ПУБЛИЧНЫЙ_IP
vless-rotate --ip ПУБЛИЧНЫЙ_IP
vless-port --ip ПУБЛИЧНЫЙ_IP
vless-name --ip ПУБЛИЧНЫЙ_IP
```

## Дополнительные параметры

```bash
bash install.sh --help
bash install.sh --port 56399                      # фиксированный порт
bash install.sh --target www.google.com           # вручную указать REALITY-домен
bash install.sh --name "Мой VPN"                  # указать своё имя
bash install.sh --strict-fail2ban                 # 2 ошибки/3 мин -> бан на 72 ч!
bash install.sh --ssh-port 2222                   # дополнительно открыть SSH-порт 2222
bash install.sh --yes                             # без подтверждающего вопроса
bash install.sh --no-upgrade                      # пропустить полное обновление пакетов
```

Не применяй `--strict-fail2ban`, пока не убедишься, что у тебя есть аварийная веб-консоль: две ошибки в пароле могут заблокировать твой IP на трое суток.

## Где лежат файлы

| Файл | Назначение |
|---|---|
| `/usr/local/etc/xray/config.json` | Рабочие настройки Xray (секреты; root + группа службы) |
| `/etc/araucaria/settings.json` | Имя профиля |
| `/usr/local/bin/araucaria` | Управление Xray |
| `/usr/local/bin/vless-link` | Показ ссылки |
| `/usr/local/bin/vless-rotate` | Смена ключей |
| `/usr/local/bin/vless-port` | Смена TCP-порта с UFW и автоматическим откатом |
| `/usr/local/bin/vless-name` | Смена названия профиля без перезапуска Xray |
| `/root/.bashrc` | Жёлтое приглашение root (отмечено блоком Araucaria) |
| `/etc/fail2ban/jail.d/araucaria-sshd.local` | Защита SSH |
| `/etc/systemd/system/xray.service.d/20-araucaria-hardening.conf` | Ограниченные права службы |
| `/var/backups/araucaria/` | Резервные копии (доступны root) |

## Если что-то пошло не так

**Xray не запускается:**

```bash
systemctl status xray --no-pager -l
journalctl -u xray -n 40 --no-pager
xray run -test -config /usr/local/etc/xray/config.json
```

**UFW:**

```bash
ufw status verbose
ss -ltnp | grep xray
```

**Fail2ban:**

```bash
fail2ban-client status sshd
```

Если случайно заблокировал свой IP, войди через аварийную консоль провайдера:

```bash
fail2ban-client set sshd unbanip ТВОЙ_ВНЕШНИЙ_IP
```

**После ошибки установки** не запускай её повторно вслепую. Установка нескольких компонентов может быть частичной. Сохрани текущую SSH-сессию и посмотри, на каком шаге остановилась программа. Самый простой путь для тестового VPS — переустановить чистую Ubuntu и повторить запуск после разбора причины.

## Установка из приватного GitHub-репозитория

Исходники хранятся в приватном репозитории `Dindinlinius/araucaria-vps-manager`. На новом VPS настрой Deploy Key с правами **только чтения** (инструкция: GitHub → Settings → Deploy keys), проверь отпечаток SSH GitHub и выполни `git clone`. После этого на **чистом** VPS запусти `bash install.sh`.

Для обновления только команд управления **уже установленной Araucaria** (без повторного запуска установщика):

```bash
cd /root/araucaria-vps-manager
GIT_SSH_COMMAND="ssh -i /root/.ssh/araucaria_deploy -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes" git pull --ff-only
python3 -m unittest discover -s tests -v
install -m 0755 araucaria.py /usr/local/bin/araucaria
for alias in vless-port vless-name; do
  if [ ! -e "/usr/local/bin/$alias" ] && [ ! -L "/usr/local/bin/$alias" ]; then
    ln -s /usr/local/bin/araucaria "/usr/local/bin/$alias"
  fi
done
araucaria commands
```

Это инструкция для версии после объединения изменений с веткой `main`. Если `vless-port` уже существует, **не перезаписывай его** через `ln -s`: проверь путь командой `ls -l /usr/local/bin/vless-port`.

Никогда не загружай в GitHub настройки действующего VPS, приватные ключи, UUID или готовые ссылки.

## Технические заметки

- Используется [официальный Xray-install](https://github.com/XTLS/Xray-install) и [спецификация REALITY](https://github.com/XTLS/Xray-docs-next/blob/main/docs/en/config/transports/reality.md). Xray скачивается на время установки из официального источника (скрипт не привязан к фиксированной версии); перед будущей публикацией рекомендуются фиксация версии и проверка источника.
- UFW открывает IPv4/IPv6 в соответствии с настройками системы. Если UFW **уже активен**, установщик сохраняет существующие политики, не удаляет чужие правила.
- Пользователь Xray запускает службу без привилегий; конфигурация имеет права `0640`, резервные копии — `0600`.
- Проверка Xray включает валидацию JSON его собственной командой, перезапуск службы и TCP-соединение с локальным портом.
- Ротация блокируется файловой блокировкой, проверяет новый конфиг и делает резервную копию перед применением.
- Автоматическое обновление **самого Xray** в этой версии не включено: обновлять вручную, предварительно сохранив конфигурацию. Автообновления касаются системных пакетов Ubuntu.
- Тесты без установки на VPS: `python3 -m unittest discover -s tests -v`.

**Статус версии:** v0.2.0-rc2 (локальные тесты, требуется полевой тест новой функции смены порта).

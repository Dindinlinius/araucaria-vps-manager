# Araucaria VPS Manager

**Установка и управление Xray-core (VLESS + REALITY + Vision) на собственном VPS — без Docker, веб-панелей и ручного редактирования JSON.**

Araucaria разворачивает одно VLESS-подключение на чистой Ubuntu, настраивает UFW и Fail2ban, создаёт готовую ссылку для ВПН-клиента и добавляет консольные команды для обслуживания сервера.

> **Статус:** `v1.0.0-rc1` — публичный предварительный релиз (release candidate). Не используйте эту версию как гарантию готовности к критически важной инфраструктуре. Стабильная `v1.0.0` будет выпущена отдельно.

## Возможности

- **Чистая установка** на Ubuntu 22.04 LTS и 24.04 LTS с systemd.
- **Официальный Xray-core:** VLESS по TCP, REALITY и Vision. Устанавливается последний стабильный выпуск; beta/pre-release не выбираются.
- **Защита SSH:** UFW с сохранением обнаруженных SSH-портов и Fail2ban (по умолчанию 5 неудачных попыток за 10 минут, блокировка на 12 часов).
- **Минимальные привилегии:** служба Xray запускается от отдельного пользователя `araucaria-xray`, с дополнительными ограничениями systemd.
- **Управление подключением:** вывести ссылку, сменить имя, порт, UUID и REALITY-ключи.
- **Управление Xray:** вручную проверить новую стабильную версию, обновить её с проверкой VPN или откатить неудачное обновление.
- **Обслуживание Ubuntu:** автоматические обновления безопасности (без автоматической перезагрузки); резервные копии перед изменениями конфигурации.
- **Восстановление после ошибок:** диагностические подсказки и возможность повторить отдельные безопасно повторяемые шаги установки, не пропуская критические ошибки.

Araucaria рассчитана на **один VPS, одну конфигурацию VLESS + REALITY и одного клиента**. Не предусмотрены веб-панель, Trojan, управление несколькими пользователями и миграция существующей конфигурации Xray.

## Быстрый старт

### Требования

- **Новый, чистый VPS** с Ubuntu **22.04 или 24.04 LTS**, systemd и доступом `root`.
- Интернет-доступ с сервера к репозиториям Ubuntu, GitHub и выбранной REALITY-цели.
- Публичный IPv4, по которому ВПН-клиент сможет подключиться к серверу.
- Доступ к аварийной консоли у провайдера — желательно на случай ошибки в SSH или файрволе.

**Важно:** Araucaria не устанавливается поверх существующего Xray и не выполняет миграцию. Используйте именно чистый VPS. Перед работой с UFW убедитесь, что знаете свой фактический SSH-порт.

### Установка `v1.0.0-rc1`

Подключитесь к VPS по SSH под `root` и выполните:

```bash
apt-get update && apt-get install -y git
git clone --depth 1 --branch v1.0.0-rc1 https://github.com/Dindinlinius/araucaria-vps-manager.git
cd araucaria-vps-manager
bash install.sh
```

Мы рекомендуем установку **из конкретного релизного тега**, а не из изменяемой ветки `main`. Перед выполнением проверьте содержимое `install.sh`: установщик изменяет конфигурацию сервера с правами `root`.

Установщик запросит имя профиля (по умолчанию `USAraucaria`), предложит случайный свободный TCP-порт в диапазоне 1024–65535 и покажет план действий. По умолчанию для REALITY используется `www.google.com:443`; проверяется доступность TLS 1.3 с сервера. Имя профиля поддерживает кириллицу, пробелы и эмодзи.

Перед вводом `yes` **проверьте разрешённые SSH-порты**. Не закрывайте исходную SSH-сессию до успешного повторного входа через второе окно. После установки импортируйте выданную `vless://`-ссылку в совместимый ВПН-клиент, например Hiddify, и проверьте интернет с клиентского устройства.

Если у хостинга есть **внешний файрвол / Security Group**, разрешите там выбранный TCP-порт VLESS отдельно: Araucaria управляет UFW на самом VPS, но не настройками провайдера.

### Параметры установки

| Параметр | Назначение |
| --- | --- |
| `--name "Мой VPN"` | Имя профиля в ссылке |
| `--port 56399` | Выбрать конкретный TCP-порт вместо случайного |
| `--target www.google.com` | Указать REALITY-цель / SNI |
| `--ssh-port 2222` | Дополнительно разрешить SSH-порт, не определённый автоматически |
| `--strict-fail2ban` | Строгий режим: 2 ошибки за 3 минуты, бан на 72 часа |
| `--no-upgrade` | Пропустить полное обновление установленных пакетов Ubuntu |
| `--yes` | Подтвердить установку без интерактивных вопросов |
| `--help` | Показать справку |

Пример: `bash install.sh --name "Home VPS" --port 56399`.

Строгий Fail2ban и `--yes` не рекомендуются для первого запуска без доступа к аварийной консоли провайдера.

## Команды управления

Все команды выполняются на VPS под `root`.

| Команда | Что делает |
| --- | --- |
| `vless-link` | Показать актуальную VLESS-ссылку |
| `vless-name` | Интерактивно изменить название профиля |
| `vless-name "Мой VPN"` | Указать имя сразу |
| `vless-port` | Выбрать новый порт: случайный или вручную |
| `vless-port --random` | Автоматически выбрать случайный доступный порт |
| `vless-port 38421` | Установить указанный порт |
| `vless-rotate` | Сменить UUID, ключи REALITY и Short ID |
| `araucaria status` | Проверить Xray, UFW и Fail2ban |
| `araucaria xray check` | Узнать установленную и последнюю стабильную версии Xray |
| `araucaria xray update` | Обновить Xray с подтверждением работоспособности VPN |
| `araucaria xray rollback` | Восстановить Xray при незавершённом обновлении |
| `araucaria commands` | Показать краткую памятку по командам |
| `araucaria --help` | Полная справка |

**Переименование:** меняется только отображаемое имя в ссылке. UUID, ключи и порт не затрагиваются, служба Xray не перезапускается.

**Смена порта:** Araucaria разрешает новый порт в UFW, меняет конфигурацию Xray, проверяет запуск и затем закрывает старое правило. При некоторых ошибках предусмотрен откат. После смены порта обязательно **импортируйте новую ссылку** в клиент и проверьте доступ извне.

**Ротация ключей:** создаются новые UUID и параметры REALITY. **Прежняя ссылка перестанет работать**; заранее убедитесь, что сможете обновить конфигурации своих клиентов.

Если автоматическое определение внешнего IP не удалось, задайте его вручную:

```bash
vless-link --ip ВНЕШНИЙ_IP_VPS
```

Параметр `--ip` также доступен для `vless-name`, `vless-port` и `vless-rotate`.

## Обновление Xray и откат

Araucaria **не обновляет Xray автоматически**. Для управления движком:

```bash
araucaria xray check
araucaria xray update
araucaria xray rollback
```

`araucaria xray update` предлагает обновление только при наличии **более новой стабильной версии** Xray-core. Обновление:

1. Показывает установленную и доступную версии и требует явного `yes`.
2. Скачивает официальный архив и файл контрольных сумм, сверяет SHA-256 и проверяет совместимость бинарника с текущей конфигурацией Xray.
3. Сохраняет предыдущий исполняемый файл и резервную копию конфигурации, заменяет бинарник и перезапускает службу.
4. Проверяет, что Xray запустился и слушает прежний порт, затем просит проверить подключение в ВПН-клиенте **при открытой SSH-сессии**.
5. При ответе `yes` сохраняет новую версию; при `no` пытается восстановить предыдущий бинарник и работоспособность службы.

UUID, REALITY-ключи, имя профиля и порт **не изменяются** при обычном обновлении движка, поэтому VLESS-ссылка, как правило, остаётся прежней.

При ошибке запуска или потере интерактивного ввода предусмотрена попытка автоматического отката. При аварийном завершении процесса или выключении VPS он **не гарантирован**: после восстановления доступа может понадобиться `araucaria xray rollback`. Проверка локальной службы также не гарантирует доступность VPN со всех внешних сетей.

**Не запускайте обновление без доступного SSH и желательно аварийной консоли провайдера.**

### Откуда берётся Xray

Первоначальная установка использует официальный проект [XTLS/Xray-install](https://github.com/XTLS/Xray-install). Araucaria загружает его скрипт из **закреплённого коммита** `e741a4f56d368afbb9e5be3361b40c4552d3710d`, проверяет его SHA-256 и синтаксис Bash перед запуском.

Сам движок Xray выбирается по **последнему официальному стабильному релизу** GitHub `XTLS/Xray-core` на момент установки (без beta/pre-release). Официальный установщик проверяет контрольную сумму архива Xray. Контрольные суммы выявляют повреждение или изменение скачанных файлов, но сами по себе не заменяют независимую подпись издателя.

## Безопасность

- **SSH-пароль, вход под `root` и возможность входа по паролю Araucaria не меняет.** Для постоянно доступного VPS рекомендуем настроить SSH-ключи и отдельно ограничить доступ.
- Для чистого сервера UFW разрешает SSH и выбранный VLESS-порт, а остальные входящие соединения запрещает по умолчанию.
- Fail2ban защищает SSH от повторных неуспешных попыток. Значения по умолчанию: 5 попыток / 10 минут / блокировка 12 часов.
- Xray запускается от `araucaria-xray` с ограничениями systemd.
- Автоматические обновления безопасности Ubuntu включаются; автоматическая перезагрузка не выполняется, обновление Xray остаётся ручным.
- Готовая `vless://`-ссылка, UUID, приватный ключ REALITY и содержимое `config.json` — **секретные данные**. Не публикуйте их в Issues и скриншотах.
- REALITY и случайный порт не обеспечивают гарантированной защиты от блокировок и не заменяют отдельную настройку безопасности VPS.

## Диагностика

```bash
araucaria status
systemctl status xray --no-pager -l
journalctl -u xray -n 50 --no-pager
ufw status verbose
fail2ban-client status sshd
ss -ltnp
```

Проверить конфигурацию без изменения настроек:

```bash
xray run -test -config /usr/local/etc/xray/config.json
```

Если VPN-клиент не подключается, сначала проверьте доступность выбранного TCP-порта с внешнего устройства и правила файрвола провайдера.

Установщик показывает причину сбоя и рекомендации для проблемного шага. Некоторые исправимые операции можно повторить **в том же процессе**. Не запускайте `install.sh` поверх частично установленной системы без диагностики: установщик предназначен для чистой Ubuntu.

После установки жёлтый цвет приглашения Bash в текущей SSH-сессии можно включить командой `source /root/.bashrc`; при новом входе настройки применятся автоматически.

Если Ubuntu сообщает о необходимости перезагрузки, сначала подтвердите, что повторный SSH-вход работает, и только затем перезагружайте VPS.

### Где лежат файлы

| Путь | Назначение |
| --- | --- |
| `/usr/local/etc/xray/config.json` | Действующая конфигурация Xray (содержит секреты) |
| `/etc/araucaria/settings.json` | Имя VLESS-профиля |
| `/var/backups/araucaria/` | Резервные копии |
| `/usr/local/bin/araucaria` | Программа управления |
| `/usr/local/bin/vless-*` | Команды-ярлыки |
| `/etc/fail2ban/jail.d/araucaria-sshd.local` | Параметры защиты SSH |
| `/etc/systemd/system/xray.service.d/20-araucaria-hardening.conf` | Защита systemd |
| `/root/.bashrc` | Оформление приглашения Bash |

## Проверки и разработка

Проект написан на Bash и Python 3. Для управления Araucaria сторонние Python-пакеты не требуются.

```bash
bash -n install.sh
python3 -m py_compile araucaria.py
python3 -m unittest discover -s tests -q
```

**Перед `v1.0.0-rc1`:** на реальном тестовом VPS с Ubuntu **24.04 LTS** пройдены чистая установка, подключение ВПН-клиента, второй SSH-вход, переименование профиля, смена порта, ротация параметров доступа и проверка работы после перезагрузки. Отдельно проверены статус UFW, Fail2ban и работа Xray от системного пользователя `araucaria-xray`.

В GitHub Actions запускаются **59 автоматических тестов** на Ubuntu 22.04 и 24.04, включая проверку контрольной суммы официального установщика, синтаксиса Bash/Python и сканирование истории Git на распространённые шаблоны секретов. Автоматические проверки не заменяют испытания на каждой конфигурации VPS; для Ubuntu 22.04 подтверждены тесты в CI, а не отдельная чистая установка на VPS.

Проблему или предложение можно описать в [Issues](https://github.com/Dindinlinius/araucaria-vps-manager/issues). Перед публикацией логов удалите ссылки, ключи, UUID и другие данные доступа.
